# Project Instructions

This repository is a single-file web app intended for GitHub Pages.

## Layout

- `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` stay at the top level.
- `index.html` is the GitHub Pages entry point.
- `00_planning/` contains notes and sketches.
- `01_data/` contains data files.
- `02_validation/` contains hand calculations and test cases.
- `03_output/` contains screenshots and exported results.

## File placement

Save every new file in the folder that matches its purpose. Do not put planning notes, data, validation artifacts, or output files at the top level.
